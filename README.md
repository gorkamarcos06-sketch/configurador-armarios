# Configurador de armarios

Configurador web de armarios modulares (Spaceo Evo'M) con vista 2D y 3D, interior editable, tiradores, transporte y presupuesto con referencias de Leroy Merlin.

## Uso
Abre `index.html` en el navegador (necesita conexión a internet para cargar la vista 3D y las fuentes).

## Publicar con GitHub Pages
Settings → Pages → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save.
